# AI Writing — Loading Studies

`index.html` をブラウザで開くと、3案の動くモックアップを比較できます。ビルドやサーバー起動は不要です。外部フォント・画像・ライブラリ・APIへの通信もありません。

| 案 | 表現 | 想定する印象 |
| --- | --- | --- |
| 01 Warm Bloom（おすすめ） | 生成りとテラコッタ。花のモチーフが呼吸するように動く | 温かさ、落ち着き。Claudeを連想する独自デザイン |
| 02 Neural Orbit | セージグリーン。3つの軌道を粒子が巡る | 情報のつながり、AIの思考 |
| 03 Quiet Draft | ラベンダー。紙に文章の行が現れる | 丁寧な執筆、読みやすさ |

## 操作

- 左側（スマートフォンでは上部）のカードでデザインを切り替えます。
- 約18秒で、内容の整理 → 文章の作成 → 表現の調整 → 完了へ進みます。
- 「再生する」で最初から再生。「完了を表示」で完了画面へ移ります。
- 「作成を中止」で停止表示。「もう一度見る」で再開します。
- 「動きを止める」は装飾のアニメーションのみ停止します。デモの経過時間は進みます。
- OSの「動きを減らす」設定ではアニメーションを無効化します。

## ファイル

- `index.html` / `styles.css` / `app.js`：独立したモックアップ本体
- `preview-bloom.png` / `preview-orbit.png` / `preview-draft.png`：PC幅での画像
- `preview-mobile.png`：スマートフォン幅での画像
- `verify.cjs` / `verification-results.json`：この環境のPlaywrightを使った確認と結果
- `verification-baseline.json` / `scope-verification.json`：指定フォルダ外のファイル照合

このGUIDEはCode D内の3案の説明です。他のエージェントの成果物と分離するため、作成ファイルをCode Dへ移動しました。親フォルダで別の内容に更新されていたindex.htmlとREADME.mdは変更せず、このフォルダのindex.htmlは当初の作成内容から復元しています。照合用のbaselineとscope-verificationは初回作業時点の記録です。

## 実装に向けた注意点

現在の進行表示と時間はモック用の演出です。本番への導入時は実際の開始・成功・中止・失敗イベントに接続し、処理段階が取得できない場合は「作成中」の表示にします。中止ボタンも実際の通信停止処理との接続が必要です。既存システムへの組み込みとAIの文章生成は行っていません。

今回の作業は通常のautonomous-workflowで実行。段階ごとのモデル切替は未適用（not_applied）。独立した小規模モックのため現行エージェントで設計・実装・検証を実施しました。コミット・pushは対象外です。
