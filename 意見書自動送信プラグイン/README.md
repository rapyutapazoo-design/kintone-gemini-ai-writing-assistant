# 意見書 自動送信プラグイン

kintoneレコードの内容を、設定したメールアドレスへ送信するプラグインです。
**手動ボタン送信**と、**無人での定時一括送信**の両方に対応します。

## 構成（2層）

| 層 | 役割 |
|---|---|
| **kintoneプラグイン**（本ディレクトリ `src/`） | 設定画面・詳細画面の「メール送信」ボタン・確認ダイアログ・GASの呼び出し |
| **Google Apps Script**（`gas/`） | 実際のメール送信（全項目整形・添付）・送信済みフラグ更新・定時一括送信 |

kintoneプラグイン単体ではメールを送信できないため、送信処理と定時実行はGASが担います。
GASは無料枠で運用でき、時間主導トリガーで「無人でも時刻通り」の送信を実現します。

## 主な機能

- レコード詳細画面の「メール送信」ボタン（送信前に確認ダイアログ）
- 特定ステータス／特定フィールド値 ＋ 指定時刻での定時一括送信
- 宛先（TO/CC/BCC）をプラグイン設定画面で管理
- レコード全項目を「項目名: 値」形式に自動整形して本文化（除外フィールド指定可）
- 件名テンプレート（`{フィールドコード}` で差し込み）
- 添付ファイルフィールドの中身をメールに添付
- 送信済みフラグをレコードに記録して重複送信を防止

## セットアップ

### 1. GAS側
`gas/README.md` の手順に従ってGASをデプロイし、`/exec` URLと共有シークレットを用意します。

### 2. プラグインのビルドとアップロード

```bash
npm install
npm run build      # dist/plugin.zip を生成（初回は private.ppk を自動生成）
npm run upload     # kintoneへアップロード（要ログイン情報）
```

開発時は `npm start`（build watch + upload）も利用できます。

### 3. プラグイン設定
kintoneのアプリ設定でプラグインを追加し、設定画面で以下を入力します。
- GAS Web App URL / 共有シークレット
- 宛先（TO/CC/BCC）
- 件名テンプレート・本文ヘッダー/フッター・除外フィールド・添付ファイルフィールド
- 自動送信条件（ステータス or フィールド値）
- 送信済みフラグフィールド・送信日時フィールド
- 定時送信スケジュール（毎日/毎週・時刻）

設定保存後、GASエディタで `setupTrigger` を実行してトリガーを作成します（`gas/README.md` 参照）。

## アプリ側に用意するフィールド（例）

| 用途 | フィールド型 | 例（フィールドコード） |
|---|---|---|
| 送信済みフラグ | チェックボックス または 文字列1行 | `送信済み` |
| 送信日時（任意） | 日時 | `送信日時` |
| 自動送信の判定（フィールド値方式の場合） | 任意 | `状態` |
| 添付（任意） | 添付ファイル | `添付ファイル` |

## セキュリティ

- kintone APIトークンはGASのスクリプトプロパティに保管し、ブラウザ側には置きません。
- 共有シークレットはkintoneのProxyConfigに秘匿保存し、GAS呼び出し時に自動付与されます。
- GASの `doPost` は共有シークレットを検証し、不一致のリクエストを拒否します。
