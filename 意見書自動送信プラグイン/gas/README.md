# GAS（Google Apps Script）送信エンジン セットアップ手順

このプラグインの「実際のメール送信」と「無人の定時一括送信」は、Google Apps Script（GAS）が担当します。
以下の手順で 1 度だけセットアップしてください。

## 1. GASプロジェクトの作成

1. <https://script.google.com/> で新しいプロジェクトを作成。
2. `Code.gs`（本ディレクトリの内容）をエディタに貼り付けて保存。

## 2. スクリプトプロパティの登録

「プロジェクトの設定（⚙）> スクリプト プロパティ」で以下を登録します。

| プロパティ名 | 値 | 例 |
|---|---|---|
| `KINTONE_DOMAIN` | kintoneのドメイン | `example.cybozu.com` |
| `KINTONE_APP_ID` | 対象アプリのID | `123` |
| `KINTONE_API_TOKEN` | レコード閲覧・編集・ファイル読み込み権限つきAPIトークン | `xxxxxxxx...` |
| `SHARED_SECRET` | 任意の秘密文字列（プラグイン設定と同じ値） | `kf93jf...`（推測困難な長い文字列） |

> `PLUGIN_CONFIG` はプラグインの設定保存時に自動連携されるため、手動登録は不要です。

### kintone APIトークンの権限
- レコード閲覧
- レコード編集（送信済みフラグの書き込みに必要）
- ファイル読み込み（添付ファイル送信を使う場合）

## 3. ウェブアプリとしてデプロイ

1. 「デプロイ > 新しいデプロイ」→ 種類「ウェブアプリ」。
2. 設定:
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**（kintoneプロキシからの匿名POSTを受けるため）
3. デプロイして表示される **`/exec` で終わるURL** をコピー。
4. このURLと `SHARED_SECRET` を、kintoneのプラグイン設定画面「1. 接続設定」に入力して保存。

> 「全員アクセス可」でも、`doPost` は冒頭で `SHARED_SECRET` を検証するため、
> シークレットを知らないリクエストはすべて拒否されます。

## 4. 初回の権限承認 & 設定連携

1. プラグイン設定画面で設定を保存すると、設定内容（宛先・条件・スケジュール等）がGASに連携されます。
2. GASエディタで `scheduledSend` を一度手動実行し、Gmail送信などの**権限承認**を完了させます。

## 5. 定時送信トリガーの設定

プラグインで設定を保存したあと、GASエディタで関数 **`setupTrigger`** を一度手動実行してください。
`PLUGIN_CONFIG` のスケジュール設定（毎日／毎週・時刻）に従って、`scheduledSend` の時間主導トリガーが作成されます。

> スケジュールを変更したら、再度 `setupTrigger` を実行してトリガーを作り直してください。
> 時間主導トリガーは指定時刻に対して±数分の誤差があります。

## 動作の流れ

- **手動送信**: レコード詳細の「メール送信」ボタン → 確認ダイアログ → プラグインがGASの `doPost(action=sendOne)` を呼ぶ → GASが該当レコードを整形・添付付きで送信 → 送信済みフラグを更新。
- **定時送信**: 時間主導トリガー → `scheduledSend` → 「条件に合致 かつ 未送信」のレコードを抽出 → 各レコードを送信 → 送信済みフラグを更新。

## 注意点

- Gmailの1日あたり送信上限（無料アカウントは約100宛先/日、Google Workspaceは約1,500宛先/日）に注意。
- 添付ファイルの合計サイズはGmailの上限（約25MB）に依存します。
- 1件送信成功ごとにフラグを更新するため、途中で失敗しても既送信分が重複送信されることはありません。
