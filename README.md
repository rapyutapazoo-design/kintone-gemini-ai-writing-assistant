# 🏢 Kintone 意見書アプリ用 Gemini連携プラグイン

マンション管理組合向けのKintone「意見書アプリ」において、生成AI（Gemini API）を活用して住民の意見起案をサポートし、管理者の業務負担を軽減するためのKintoneプラグインです。

## ✨ 主な機能

1. **意見書の起案サポート（住民向け）**
   * 簡単なメモやキーワードを入力するだけで、AIが「件名」と「本文」のドラフト（下書き）を自動生成します。
   * 文章の長さ（簡潔/標準/詳細）もオプションで選択可能です。
2. **意見書の要約機能（管理者向け）**
   * 長文で複雑な意見書の内容を、理事会資料として扱いやすいようにワンクリックで要約します。
   * 要約結果は、見出しや箇条書きを用いた見やすいレイアウトで専用フィールドに自動保存されます。
3. **セキュアなアーキテクチャ**
   * Kintone標準のプロキシAPI（`kintone.plugin.app.proxy`）を利用しており、GeminiのAPIキーはクライアントサイド（ブラウザ）から完全に隠蔽されます。
4. **モデルの動的取得と実疎通確認**
   * プラグイン設定画面でAPIキーを入力すると、そのキーで利用可能なGeminiモデルの一覧をその場で取得します。
   * モデルを選択すると、実際に`generateContent`を呼び出す軽量な実疎通確認を自動実行し、「一覧には出るが実際は使えない」モデルを保存前に検出します。
5. **フィールド・プロンプトの外部化（複数アプリ対応）**
   * 対象フィールドコード・ボタン設置スペースID・プロンプト文面・ボタン文言をすべて設定画面から変更できます。ソースコードを直接編集することなく、意見書アプリ以外でも同じプラグインを利用できます。


## 🛠️ 開発・ビルド環境のセットアップ

プラグインのコードを修正し、新しくパッケージ化する際の手順です。

### 1. 依存ライブラリのインストール
```bash
cd opinion-box-plugin
npm install
```

### 2. プラグインのビルド
```bash
npm run build
```
ビルドが成功すると、`opinion-box-plugin/dist/` ディレクトリ内に `plugin.zip` が生成されます。

> **Note**: ビルドには `private.ppk`（秘密鍵）が必要です。このファイルはセキュリティの観点からリポジトリには含まれていないため、初回開発時はKintone公式ツールを用いて新規に鍵を生成するか、管理者から安全な経路で取得して `opinion-box-plugin` ディレクトリ直下に配置してください。

## 🔁 複数アプリでの利用について

Gemini連携プラグインはopinion-box-pluginに一本化しています。「お問い合わせアプリ」でも同じプラグインを追加し、設定画面の「お問い合わせアプリ用の初期値を入れる」プリセットを起点にフィールドコードを調整して利用してください。

## 🚀 Kintone環境への導入手順

1. **プラグインのインストール**
   * Kintoneの「kintoneシステム管理 > プラグイン」画面を開きます。
   * 「読み込む」ボタンから、ビルド済みの `dist/plugin.zip` をアップロードします。
2. **アプリへの適用**
   * 対象アプリ（「意見書アプリ」または「お問い合わせアプリ」等）の設定画面を開き、「プラグイン」メニューから「Opinion Box」プラグインを追加します。
3. **設定画面での設定**
   * 追加したプラグインの「歯車アイコン（設定）」をクリックします。
   * 以下の流れで設定します。
     1. Google AI Studioで取得した **Gemini APIキー** を入力する
     2. 利用可能なモデル一覧が自動取得される
     3. モデルを選択すると自動で実疎通確認（`generateContent`の実呼び出し）が行われる
     4. 対象アプリに応じてプリセットボタンでフィールドコードの初期値を入れ、必要に応じて調整する
     5. 内容を確認して保存する
   * アプリの設定を更新（本番反映）すると、プラグインが稼働を開始します。

> **Note**: プラグインを更新すると、kintoneの仕様上APIキーは引き継がれません。更新後は必ず設定画面を開き、APIキーを再入力して保存してください。
