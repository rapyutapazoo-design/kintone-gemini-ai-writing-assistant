# 🏢 Kintone 意見書アプリ用 Gemini連携プラグ

マンション管理組合向けのKintone「意見書アプリ」において、生成AI（Gemini API）を活用して住民の意見起案をサポートし、管理者の業務負担を軽減するためのKintoneプラグインです。

## ✨ 主な機能

1. **意見書の起案サポート（住民向け）**
   * 簡単なメモやキーワードを入力するだけで、AIが「件名」と「本文」のドラフト（下書き）を自動生成します。
   * 文章の長さ（簡潔/標準/詳細）もオプションで選択可能です。
2. **意見書の要約機能（管理者向け）**
   * 長文で複雑な意見書の内容を、理事会資料として扱いやすいようにワンクリックで要約します。
   * 要約結果は、見出しや箇条書きを用いた見やすいレイアウトで専用フィールドに自動保存されます。
3. **セキュアなアーキテクチャ**
   * Kintone標準のプロキシAPI（`kintone.plugin.app.proxy`）を利用しており、GeminiのAPIキーはクライアントサイド（ブラウザ）から完全に隠蔽されます。

## 📁 ディレクトリ構成

```text
.
├── guide_display_universal.js   # UIガイド表示用カスタマイズJS（プラグイン外）
├── opinion-box-plugin/          # Kintoneプラグイン本体のソースコード
│   ├── src/                     # プラグインのソースコード（js, css, html等）
│   ├── dist/                    # ビルド後のプラグインファイル（plugin.zip）が生成される場所
│   ├── private.ppk              # プラグイン署名用秘密鍵（※Git管理外）
│   └── package.json             # 依存ライブラリ定義
└── README.md                    # 本ドキュメント
```

## 🛠️ 開発・ビルド環境のセットアップ

プラグインのコードを修正し、新しくパッケージ化する際の手順です。

### 1. 依存ライブラリのインストール
```bash
cd opinion-box-plugin
npm install
```

### 2. プラグインのビルド
```bash
npm run build
```
ビルドが成功すると、`opinion-box-plugin/dist/` ディレクトリ内に `plugin.zip` が生成されます。

> **Note**: ビルドには `private.ppk`（秘密鍵）が必要です。このファイルはセキュリティの観点からリポジトリには含まれていないため、初回開発時はKintone公式ツールを用いて新規に鍵を生成するか、管理者から安全な経路で取得して `opinion-box-plugin` ディレクトリ直下に配置してください。

## 🚀 Kintone環境への導入手順

1. **プラグインのインストール**
   * Kintoneの「kintoneシステム管理 > プラグイン」画面を開きます。
   * 「読み込む」ボタンから、ビルド済みの `dist/plugin.zip` をアップロードします。
2. **アプリへの適用**
   * 対象の「意見書アプリ」の設定画面を開き、「プラグイン」メニューから「Opinion Box」プラグインを追加します。
3. **APIキーの設定**
   * 追加したプラグインの「歯車アイコン（設定）」をクリックします。
   * Google AI Studioで取得した **Gemini APIキー** と、使用するモデル名（例: `gemini-2.5-flash`）を入力して保存します。
   * アプリの設定を更新（本番反映）すると、プラグインが稼働を開始します。
