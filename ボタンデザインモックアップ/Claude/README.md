# 生成ボタン Claude風 モックアップ（公式ロゴ寄せ）

`index.html` をブラウザで開くだけで確認できます（ビルド不要・外部通信なし・外部フォント不使用）。先頭に「公式ロゴ（参考）」の近似表示、続いて現行の青ボタン（Gemini）と A〜D 案を「通常 / ホバー / 押下 / 無効（生成中） / フォーカス」で並べています。ヘッダーのボタンでモバイル表示（幅100%・390px）に切り替えられます。ボタン文言は「Claudeでお知らせを作成」です。

## 色の出所
- スパークのテラコッタ `#D97757`: 参考画像3のスパーク部分のピクセル値 (217,119,87)。画像4の背景は (216,119,86) = `#D87756` で、ほぼ同色のため画像3の値を採用。
- 文字の黒 `#141413`: 画像3のワードマークの最頻色 (20,20,19)。
- 地: 白 `#FFFFFF`。
- 補助色（ホバー・押下用の薄いテラコッタ `#FBEFE9` `#F5DCD0`、濃い `#C9633F`、明るい `#E38C6F`、ダークのホバー `#2B2A28`）は上記から派生させた値で、公式の値ではありません。

### A のコントラスト調整（どちらにしたか）
`#D97757` に白文字は 3.12:1 で 4.5:1 に届きません。そこで **地は公式のテラコッタ `#D97757` のまま、文字を `#141413` にしました**。理由は、画像4の「ブランド色そのものの地」の見た目を保てること、黒文字で 5.90:1 と余裕があること、ロゴのワードマークの色とも揃うことです（地を濃くする方法は画像4の色から離れるため採りませんでした）。スパークは文字ではなくアイコンなので白のままです。

## おすすめ
- **B（ロゴの雰囲気そのまま）**: 白地・黒セリフ・テラコッタのスパークで、kintone の白〜薄グレーの画面になじみ、コントラストも最高水準です。迷ったらこちらを推奨します。
- **A（画像4の踏襲）**: ブランド色の面を強く出したい場合。主役のボタンにする場合に向きます。
- C はダーク運用向け、D は控えめにしたい場合の候補です。

## 本番へ反映する手順
1. `ai-writing-assistant-plugin/src/js/desktop.js` の `AI_LOGO_SVG` を上記スタンドアロン SVG に置き換えます。色は `currentColor` なので、アイコンを囲む要素の `color` で決まります（A は白、B/C/D は `#D97757`）。
2. `BTN_STYLE` を採用案のクラスの通常状態（`.bt-x { ... }`）の宣言に置き換えます。`font-family` は `"Tiempos Headline","Tiempos Text",Georgia,"Hiragino Mincho ProN","Yu Mincho",serif` です。
3. 注意: `BTN_STYLE` は `btn.style = ...` で付ける inline style のため、`:hover` `:active` `:disabled` `:focus-visible`、`::after`（C のシマー）、`@keyframes`、`prefers-reduced-motion` は書けません。これらは `desktop.css` 側に出し、ボタンに専用クラスを付けて `.クラス:hover { ... }` の形で定義してください。inline style が優先されるので、hover で変える背景などは inline 側から外す必要があります。
4. 無効（生成中）の見た目は、ボタンに `disabled` を付ける実装にしてください。無効時に opacity は使っていません。スパークが回転します。
5. モバイルの `width:100%` は既存コードの `btn.style.width = '100%'` がそのまま使えます。
6. `index.html` の `.is-hover` `.is-active` `.is-focus` は、状態を並べて見せるためだけの補助クラスです。本番には不要です。
7. ボタン文言はプラグイン設定の `btn_label_draft` で変更でき、「Claudeでお知らせを作成」と入力すれば反映されます。

## 商標・ロゴの利用に関する注記
このモックアップは社内での検討用です。スパークとワードマーク風表示は、公式ロゴの完全な複製ではなく、雰囲気を寄せた手作業の近似です（画像ファイルも同梱していません）。本番で公式ロゴを使う場合は、Anthropic のブランドガイドラインを確認してください。

## アクセシビリティ
- `prefers-reduced-motion: reduce` で全アニメーション（スパークの回転・シマー・遷移）を停止します。
- フォーカスリング（`:focus-visible`）は全案で 2〜3px のアウトラインです。
