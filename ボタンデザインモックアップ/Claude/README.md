# 生成ボタン Claude風 モックアップ

`index.html` をブラウザで開くだけで確認できます（ビルド不要・外部通信なし）。現行の青ボタン（Gemini）を先頭に置き、A〜D 案を「通常 / ホバー / 押下 / 無効（生成中） / フォーカス」で並べています。ヘッダーのボタンでモバイル表示（幅100%・390px）に切り替えられます。

## 案の一覧

| 案 | コンセプト | 特徴 | 文字×背景のコントラスト比 |
|---|---|---|---|
| A | テラコッタ塗り | `#BA5532`→`#A64A2A` の微グラデ、白文字、12本スパーク、角丸10px。無効時はスパークがゆっくり回る | 白×#BA5532 = 4.74 / 白×#A64A2A = 5.78 / ホバー白×#8F3F20 = 7.24 |
| B | クリーム地+テラコッタ枠 | `#FAF9F5` 地、枠 `#C6613F`、文字 `#8F3F20`、ピル型。ホバーでスパークが90度回る | #8F3F20×#FAF9F5 = 6.87 / ホバー×#F3E3D3 = 5.77 / 押下×#EBD2BC = 4.99 |
| C | ダーク | `#262624` 地、文字 `#F0EEE6`、スパーク `#D97757`、ホバーでシマー | #F0EEE6×#262624 = 13.05 / ホバー×#30302E = 11.38 / スパーク#D97757×#262624 = 4.86 |
| D | ミニマル・エディトリアル | 明朝系、角丸2px、テラコッタの下線、小さな4点星。ホバーで薄いベージュ | #3D3929×白 = 11.57 / ×#F5F5F5 = 10.61 / ホバー×#EFE9DA = 9.55 |

参考: 現行の白×#2962FF = 4.90。

### A のコントラスト調整
Claude のブランド色そのまま（#D97757）では 白文字 3.12、#C6613F でも 4.05 で 4.5:1 に届きません。このため A は一段濃い `#BA5532`（4.74）から始まるグラデーションにしました。ブランド色の鮮やかさは、スパークのアイコンと B/C/D のアクセントで補っています。
B の枠線 `#C6613F` は背景 #FAF9F5 に対して非文字要素の基準 3:1 を満たします。

## おすすめ: B（クリーム地+テラコッタ枠線）
- kintone の白〜薄グレーの画面で浮きすぎず、レコード画面にある他のボタンと並べても主張が強すぎません。
- Claude 風（クリーム・テラコッタ）の雰囲気が、ローディング画面の「Claude D」案とも揃います。
- コントラスト比が全状態で 4.99 以上です。
- 画面の主役にしたい場合は A、ダークテーマの運用なら C が候補です。

## 本番へ反映する手順
1. `ai-writing-assistant-plugin/src/js/desktop.js` の `AI_LOGO_SVG` を、`index.html` の `SPARK`（D 案なら `STAR`）の SVG に置き換えます。色は `currentColor` なので、`.sp` の `color`（ボタンの文字色）で決まります。
2. `BTN_STYLE` を採用案のクラスの通常状態（`.bt-x { ... }`）の宣言に置き換えます。
3. 注意: `BTN_STYLE` は `btn.style = ...` で付ける inline style のため、`:hover` `:active` `:disabled` `:focus-visible`、`::after`（C のシマー）、`@keyframes`、`prefers-reduced-motion` は書けません。これらは `desktop.css` 側に出し、ボタンに専用クラスを付けて `.クラス:hover { ... }` の形で定義してください。inline style が優先されるので、hover で変える背景などは inline 側から外す必要があります。
4. 無効（生成中）の見た目は、ボタンに `disabled` を付ける実装にしてください。`.sp` が回転します。
5. モバイルの `width:100%` は既存コードの `btn.style.width = '100%'` がそのまま使えます。
6. `index.html` の `.is-hover` `.is-active` `.is-focus` は、モックアップで状態を並べて見せるためだけの補助クラスです。本番には不要です。

## ラベル文言
ボタンの文言はプラグイン設定の `btn_label_draft`（お知らせ作成ボタン）で変更します。コードを直す必要はなく、設定画面で「Claudeでお知らせを作成」と入力すれば反映されます。モックアップの文言は「Claudeでお知らせを作成」、生成中は「生成中…」です。

## アクセシビリティ
- `prefers-reduced-motion: reduce` で全アニメーション（スパークの回転・シマー・遷移）を停止します。
- フォーカスリング（`:focus-visible`）は全案で 2〜3px のアウトラインです。
