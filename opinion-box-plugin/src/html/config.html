AI文章作成アシスタント（Gemini）プラグイン設定

1. Gemini接続設定
Gemini APIキー*
Google AI Studio等で取得したAPIキーを入力してください。
一度保存したAPIキーはkintoneに保持されます。変更しない場合は空欄のまま保存してください。セキュリティのため保存済みのキーは画面に表示しません（キーを変更するときだけ新しいキーを入力してください）。

Geminiモデル*
保存済みのAPIキー（またはこの画面で入力したAPIキー）を使って、利用可能なモデルの一覧を自動取得します。既定では文章生成に適した推奨モデルのみを表示します。モデルを選択すると自動で疎通確認を行います。疎通確認はモデル情報の取得のみで行い、文章生成は行いません（課金されません）。
kintoneには外部APIの応答時間に制限があるため、高速なモデルを推奨します。一覧の「高速／標準／低速」はモデル名から推定した目安（推定）です。

3. フィールド設定
意見書・お問い合わせ向けフィールド構造
意見書・お問い合わせ向けの初期値です。その他の用途では手動で選択してください。
AIへの指示・メモ フィールド*
利用者が入力する、AIへの指示やメモを保持するフィールドです。
件名 出力先フィールド
AIが生成した件名の出力先フィールドです。使用しない場合は「（使用しない）」を選択してください。
本文 出力先フィールド*
AIが生成した本文の出力先フィールドです。リッチエディターにも対応しています。
プロンプト退避先フィールド
「生成後に指示・メモを自動で削除する」をONにした場合に、削除前の内容を退避するフィールドです。文字列（複数行）のみ選択できます。全世代が追記されます。使用しない場合は「（使用しない）」を選択してください（この場合、自動削除は復元不可の単純クリアとして動作します）。
復元ボタン設置スペース
退避したプロンプトを復元するボタンを設置するスペースフィールドのIDです。退避先フィールドが未設定、またはレコード上の退避内容が空の場合はボタンは表示されません。
生成前の上書き確認
件名・本文にすでに入力内容がある状態でAI生成を実行したとき、上書きしてよいか確認ダイアログを表示します。
下書きボタン設置スペース*
下書き生成ボタンを設置するスペースフィールドのIDです。
4. 生成オプション

プロンプトの自動退避・復元

ONにすると、下書き生成が成功したときに「AIへの指示・メモ」入力欄を自動でクリアします（既定はOFF。設定を変更しない限り既存アプリの動作は一切変わりません）。「3. フィールド設定」で退避先フィールドを指定している場合は、クリア前の内容が退避先フィールドに追記され、復元ボタンで元に戻せます。
退避の文字数上限
退避先フィールドに保存する全世代の合計文字数の上限です。既定100,000字（約280世代）。0で無制限。上限を超えると古い世代から自動的に削除されます。

文章の長さ

文字数の指定に使うフィールド
利用者が文章の長さ（選択肢）を指定するためのフィールドです。使用しない場合は「（使用しない）」を選択してください。
選択肢ごとの指示文
左列はフィールドの選択肢（読み取り専用）、右列に選択肢ごとの文字数指示文を入力してください。
選択肢 指示文
未選択・空欄のときの指示文
文字数フィールドが未選択、または値が空のときに使用する指示文です。空欄の場合は既定の動作（互換モード）を使用します。
文字数フィールドがまだない場合
対象アプリに「ドロップダウン」または「ラジオボタン」フィールドを追加し、以下の選択肢を設定することを推奨します。

形式
